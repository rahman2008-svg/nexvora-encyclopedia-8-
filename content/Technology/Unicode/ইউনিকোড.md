# ইউনিকোড

## সংক্ষিপ্ত পরিচিতি

ইউনিকোড (Unicode) হলো বিশ্বের বিভিন্ন ভাষা, লিপি, প্রতীক ও বিশেষ চিহ্নের অক্ষরকে কম্পিউটার ব্যবস্থায় একটি অভিন্ন মানের মাধ্যমে উপস্থাপন ও প্রক্রিয়াকরণের জন্য তৈরি আন্তর্জাতিক মান।

কম্পিউটারে লেখা সংরক্ষণ, প্রদর্শন, আদান-প্রদান এবং বিভিন্ন সফটওয়্যারের মধ্যে টেক্সট বিনিময়ের ক্ষেত্রে ইউনিকোড অত্যন্ত গুরুত্বপূর্ণ।

বাংলা, ইংরেজি, আরবি, হিন্দি, চীনা, জাপানি, কোরীয়, গ্রিক, সিরিলিকসহ বিশ্বের অসংখ্য ভাষার অক্ষর ইউনিকোডের মাধ্যমে ডিজিটাল পরিবেশে ব্যবহার করা যায়।

---

## ইউনিকোড কী

ইউনিকোড একটি character encoding standard বা অক্ষর-উপস্থাপন মান, যার উদ্দেশ্য হলো বিভিন্ন ভাষার অক্ষরকে কম্পিউটার ব্যবস্থায় একটি সুসংগঠিত ও সামঞ্জস্যপূর্ণ পদ্ধতিতে চিহ্নিত করা।

প্রতিটি Unicode character-এর একটি নির্দিষ্ট code point থাকে।

উদাহরণ হিসেবে বাংলা অক্ষর:

**অ**

এর একটি নির্দিষ্ট Unicode code point রয়েছে।

একইভাবে ইংরেজি অক্ষর, সংখ্যা, গাণিতিক প্রতীক এবং বিভিন্ন বিশেষ চিহ্নেরও Unicode code point রয়েছে।

---

## ইউনিকোডের প্রয়োজন কেন

কম্পিউটিংয়ের শুরুর দিকে বিভিন্ন ভাষার জন্য বিভিন্ন character encoding ব্যবহৃত হতো। একটি সিস্টেমে তৈরি করা লেখা অন্য সিস্টেমে খুললে অক্ষর বিকৃত হওয়া বা ভুল চিহ্ন দেখা দেওয়ার সমস্যা দেখা দিত।

এই সমস্যার একটি বড় সমাধান হলো Unicode।

ইউনিকোডের মাধ্যমে:

- বিভিন্ন ভাষার লেখা সংরক্ষণ করা যায়।
- একই নথিতে একাধিক ভাষা ব্যবহার করা যায়।
- ওয়েবসাইটে বিভিন্ন ভাষার লেখা প্রদর্শন করা যায়।
- ডেটাবেসে বহুভাষিক তথ্য রাখা যায়।
- মোবাইল অ্যাপে বিভিন্ন ভাষা ব্যবহার করা যায়।
- সফটওয়্যারের মধ্যে Unicode text বিনিময় করা যায়।

---

## ইউনিকোডের ইতিহাস

কম্পিউটারের প্রাথমিক যুগে character encoding সাধারণত সীমিত সংখ্যক অক্ষর সমর্থন করত।

ইংরেজি ভাষার জন্য ASCII ব্যাপকভাবে ব্যবহৃত হয়। কিন্তু বিশ্বের অন্যান্য ভাষার অক্ষর এতে পর্যাপ্তভাবে প্রকাশ করা সম্ভব ছিল না।

বিভিন্ন দেশ ও অঞ্চলে বিভিন্ন encoding তৈরি হওয়ার ফলে character compatibility-এর সমস্যা তৈরি হয়।

এই সমস্যার সমাধানের উদ্দেশ্যে Unicode Consortium প্রতিষ্ঠিত হয় এবং Unicode standard-এর বিকাশ শুরু হয়।

ইউনিকোড ধীরে ধীরে বিশ্বের বিভিন্ন ভাষা ও লিপির অক্ষরকে একটি একীভূত character repertoire-এর মধ্যে অন্তর্ভুক্ত করে।

---

## Unicode Consortium

Unicode Consortium হলো Unicode Standard-এর উন্নয়ন, রক্ষণাবেক্ষণ ও প্রকাশনার সঙ্গে যুক্ত একটি আন্তর্জাতিক সংস্থা।

সংস্থাটি Unicode Standard-এর বিভিন্ন সংস্করণ প্রকাশ করে এবং নতুন character ও script-এর জন্য code point নির্ধারণের প্রক্রিয়া পরিচালনা করে।

প্রযুক্তি প্রতিষ্ঠান, গবেষক, ভাষাবিদ এবং বিভিন্ন সংগঠন Unicode standard-এর উন্নয়নে অবদান রাখে।

---

## Code Point

Unicode-এর অন্যতম গুরুত্বপূর্ণ ধারণা হলো code point।

প্রতিটি Unicode character একটি নির্দিষ্ট code point দ্বারা শনাক্ত হতে পারে।

Code point সাধারণত:

**U+XXXX**

এই ধরনের hexadecimal notation-এ প্রকাশ করা হয়।

উদাহরণ:

**U+0041**

ইংরেজি বড় হাতের `A` অক্ষরের Unicode code point।

একইভাবে বিভিন্ন ভাষার অক্ষরের নিজস্ব code point রয়েছে।

---

## Unicode এবং Character

Character হলো ব্যবহারকারীর কাছে দৃশ্যমান বা ভাষাগতভাবে অর্থবহ একটি অক্ষর বা প্রতীক।

Unicode character-এর ক্ষেত্রে একটি গুরুত্বপূর্ণ বিষয় হলো:

একটি ব্যবহারকারীর কাছে একটি অক্ষর হিসেবে দেখা জিনিস কম্পিউটার অভ্যন্তরে একাধিক code point নিয়ে গঠিত হতে পারে।

বিশেষ করে বাংলা ও অন্যান্য complex script-এর ক্ষেত্রে এই বিষয়টি গুরুত্বপূর্ণ।

---

## Unicode এবং Script

Unicode শুধু নির্দিষ্ট ভাষাকে নয়, বিভিন্ন script বা লিপিকেও সমর্থন করে।

উদাহরণ:

- Latin
- Bengali
- Arabic
- Devanagari
- Greek
- Cyrillic
- Hebrew
- Thai
- Chinese
- Japanese
- Korean

এছাড়াও বহু ঐতিহাসিক ও আধুনিক script Unicode standard-এর অংশ।

# বাংলা ভাষা ও ইউনিকোড

বাংলা ভাষার ডিজিটাল ব্যবহারে Unicode অত্যন্ত গুরুত্বপূর্ণ।

বাংলা অক্ষরগুলো Unicode-এর Bengali block-এ নির্ধারিত code point ব্যবহার করে প্রকাশ করা হয়।

এর ফলে বাংলা লেখা:

- ওয়েবসাইটে
- মোবাইল অ্যাপে
- কম্পিউটারে
- ডেটাবেসে
- ই-বুকে
- সামাজিক যোগাযোগমাধ্যমে
- ডকুমেন্টে

ব্যবহার করা সম্ভব হয়েছে।

---

## বাংলা Unicode Block

বাংলা script-এর জন্য Unicode standard-এ নির্দিষ্ট code point range রয়েছে।

বাংলা অক্ষর ছাড়াও এই অংশে বিভিন্ন স্বরচিহ্ন, ব্যঞ্জনবর্ণ, কারচিহ্ন, সংখ্যা এবং অন্যান্য ভাষাগত চিহ্ন রয়েছে।

বাংলা লেখার ক্ষেত্রে শুধু আলাদা আলাদা অক্ষর নয়, বিভিন্ন combining mark-এর ব্যবস্থাপনাও গুরুত্বপূর্ণ।

---

## বাংলা অক্ষর ও Code Point

বাংলা ভাষায় অক্ষরের Unicode representation বোঝার জন্য code point ধারণা গুরুত্বপূর্ণ।

উদাহরণস্বরূপ:

- অক্ষর
- কার
- হসন্ত
- চন্দ্রবিন্দু
- অনুস্বার
- বিসর্গ

ইত্যাদি Unicode-এর মাধ্যমে আলাদাভাবে নির্ধারিত character হিসেবে ব্যবহৃত হতে পারে।

তবে ব্যবহারকারীর স্ক্রিনে এগুলো একসঙ্গে মিলিত হয়ে একটি স্বাভাবিক বাংলা লেখা হিসেবে প্রদর্শিত হয়।

---

## Combining Character

কিছু Unicode character একা একটি সম্পূর্ণ দৃশ্যমান glyph তৈরি না করে অন্য character-এর সঙ্গে যুক্ত হয়ে দৃশ্যমান রূপ তৈরি করে।

এই ধরনের character-কে combining character বলা হয়।

বাংলা ভাষায় বিভিন্ন কারচিহ্ন ও অন্যান্য চিহ্নের ক্ষেত্রে এই ধারণা গুরুত্বপূর্ণ।

---

## Unicode এবং বাংলা কারচিহ্ন

বাংলা লেখায়:

- া
- ি
- ী
- ু
- ূ
- ে
- ৈ
- ো
- ৌ

ইত্যাদি চিহ্ন মূল ব্যঞ্জনবর্ণের সঙ্গে যুক্ত হয়ে বিভিন্ন শব্দের গঠন তৈরি করে।

কম্পিউটারকে এগুলো সঠিকভাবে প্রদর্শনের জন্য Unicode processing এবং text shaping ব্যবস্থার প্রয়োজন হয়।

---

## হসন্ত ও যুক্তবর্ণ

বাংলা লিপির একটি গুরুত্বপূর্ণ বৈশিষ্ট্য হলো যুক্তবর্ণ।

একাধিক ব্যঞ্জনবর্ণ নির্দিষ্ট নিয়মে যুক্ত হয়ে একটি জটিল লিখিত রূপ তৈরি করতে পারে।

এক্ষেত্রে হসন্ত বা virama গুরুত্বপূর্ণ ভূমিকা পালন করে।

উদাহরণ:

**ক + ্ + ষ**

এ ধরনের character sequence rendering engine-এর মাধ্যমে যুক্তবর্ণের উপযুক্ত glyph-এ রূপান্তরিত হতে পারে।

---

## Unicode এবং বাংলা Rendering

Unicode character সংরক্ষণ করা এবং সেই character স্ক্রিনে সুন্দরভাবে প্রদর্শন করা একই বিষয় নয়।

Unicode character sequence-কে সঠিকভাবে glyph-এ রূপান্তরের জন্য font এবং text shaping engine প্রয়োজন।

বাংলা লেখার ক্ষেত্রে:

- Unicode
- font
- shaping engine
- rendering system

সবগুলো একসঙ্গে কাজ করে।

# UTF-8

UTF-8 হলো Unicode character encode করার একটি বহুল ব্যবহৃত encoding format।

ওয়েব, Linux, Android, programming এবং বিভিন্ন text file format-এ UTF-8 ব্যাপকভাবে ব্যবহৃত হয়।

UTF-8 variable-length encoding ব্যবহার করে। অর্থাৎ বিভিন্ন Unicode code point সংরক্ষণ করতে বিভিন্ন সংখ্যক byte ব্যবহার হতে পারে।

---

## UTF-8-এর সুবিধা

UTF-8-এর গুরুত্বপূর্ণ সুবিধাগুলোর মধ্যে রয়েছে:

- Unicode-এর বিস্তৃত character repertoire সমর্থন করে।
- ASCII-এর সঙ্গে backward-compatible।
- ওয়েবে ব্যাপকভাবে ব্যবহৃত।
- text file-এর জন্য কার্যকর।
- বিভিন্ন programming language-এ সমর্থিত।
- বহুভাষিক ডেটার জন্য উপযোগী।

---

# UTF-16

UTF-16 হলো Unicode text encode করার আরেকটি পদ্ধতি।

কিছু programming environment এবং operating system-এর অভ্যন্তরীণ text representation-এ UTF-16 ব্যবহৃত হয়েছে বা এখনও ব্যবহৃত হয়।

UTF-16 character encoding-এর ক্ষেত্রে code unit-এর ধারণা গুরুত্বপূর্ণ।

---

# UTF-32

UTF-32 প্রতিটি Unicode code point-এর জন্য fixed-size code unit ব্যবহার করে।

এটি ধারণাগতভাবে সহজ হলেও UTF-8-এর তুলনায় সাধারণ text storage-এর ক্ষেত্রে বেশি memory ব্যবহার করতে পারে।

---

## UTF-8, UTF-16 ও UTF-32

তিনটি encoding Unicode character-কে represent করতে পারে, কিন্তু তাদের storage পদ্ধতি ভিন্ন।

| Encoding | বৈশিষ্ট্য |
|---|---|
| UTF-8 | Variable-length, ওয়েবে অত্যন্ত প্রচলিত |
| UTF-16 | Variable-length code unit system |
| UTF-32 | Fixed-size code unit |
| ASCII compatibility | UTF-8-এ রয়েছে |

---

# ASCII ও Unicode

ASCII হলো পুরোনো ও সীমিত character encoding standard, যা মূলত ইংরেজি অক্ষর, সংখ্যা এবং কিছু control character-এর জন্য তৈরি হয়েছিল।

ASCII-এর character repertoire সীমিত।

Unicode-এর উদ্দেশ্য অনেক বিস্তৃত এবং বিশ্বের অসংখ্য ভাষা ও script সমর্থন করা।

Unicode Normalization
Unicode text processing-এর একটি গুরুত্বপূর্ণ বিষয় হলো normalization।
কখনো একই দৃশ্যমান text একাধিক Unicode character sequence-এর মাধ্যমে প্রকাশ করা সম্ভব হতে পারে।
Normalization-এর মাধ্যমে equivalent text representation-কে নির্দিষ্ট canonical form-এ আনা যায়।
Unicode normalization-এর প্রচলিত form হলো:
NFC
NFD
NFKC
NFKD
NFC
NFC বা Normalization Form Canonical Composition character sequence-কে canonical composed representation-এর দিকে নিয়ে যায়।
Text comparison ও storage-এর ক্ষেত্রে এটি গুরুত্বপূর্ণ হতে পারে।
NFD
NFD বা Normalization Form Canonical Decomposition character sequence-কে canonical decomposed representation-এ রূপান্তর করে।
NFKC ও NFKD
NFKC এবং NFKD compatibility equivalence-এর বিষয়ও বিবেচনা করে।
Search, indexing এবং text processing-এর নির্দিষ্ট কাজে normalization strategy গুরুত্বপূর্ণ হতে পারে।

এ ধরনের character ব্যবহার করে বিভ্রান্তিকর identifier বা domain name তৈরি করার ঝুঁকি রয়েছে।
তাই security-sensitive application-এ Unicode normalization, identifier policy এবং script restriction গুরুত্বপূর্ণ হতে পারে।

Unicode-এর ভবিষ্যৎ
ডিজিটাল যোগাযোগ যত বেশি বহুভাষিক হচ্ছে, Unicode-এর গুরুত্বও তত বাড়ছে।
ইন্টারনেট, মোবাইল computing, artificial intelligence, digital publishing, online education, software localization এবং global communication-এর ক্ষেত্রে Unicode ভবিষ্যতেও গুরুত্বপূর্ণ ভূমিকা পালন করবে।
নতুন script, symbol এবং character ব্যবহারের প্রয়োজন তৈরি হলে Unicode Standard-এ সেগুলো অন্তর্ভুক্ত করার প্রক্রিয়াও চলতে থাকবে।
সারসংক্ষেপ

ASCII-এর মতো পুরোনো সীমিত character set-এর তুলনায় Unicode অনেক বিস্তৃত ভাষা ও script সমর্থন করে।
